SOC Home Lab

A practical Security Operations Center home lab designed to simulate real-world security monitoring, threat detection and incident response. The project integrates Splunk Enterprise, Sysmon, Splunk Universal Forwarder, Windows 11 and Kali Linux, with Atomic Red Team used to simulate adversary techniques and generate realistic attack scenarios. The lab focuses on centralized log collection, security event analysis, threat hunting, detection engineering, alert triage and incident response. Attack scenarios including brute-force login attempts, PowerShell activity and suspicious process execution are simulated to evaluate detection capabilities using Splunk searches, dashboards and alerts.
